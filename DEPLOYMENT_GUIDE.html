Créer les comptes nécessaires

Avant de commencer, vous devez créer 3 comptes gratuits. Cela prend environ 15 minutes.

📊 1.1 — Supabase (Base de données PostgreSQL)
Supabase hébergera vos tables users, videos et subscriptions dans le cloud.
💳 1.2 — PayPal Developer (Paiements)
PayPal gérera les abonnements mensuels de 25$ (Pro) et 79$ (Entreprise).
🤖 1.3 — Replicate (Génération Vidéo IA)
Replicate exécute les modèles IA qui génèrent vos vidéos.
2

Configurer Supabase

2.1 — Récupérer les clés API
Dans votre projet Supabase, allez dans Project Settings → API.
ValeurDescription
Project URLCopier dans SUPABASE_URL
service_role keyCopier dans SUPABASE_SERVICE_ROLE_KEY
⚠️ La service_role key contourne la sécurité RLS. Ne la partagez jamais côté client.
2.2 — Créer les tables (SQL Editor)
Dans Supabase, cliquez sur SQL Editor → New query. Copiez-collez ce script :
-- Users table
create table if not exists users (
  id uuid primary key default gen_random_uuid(),
  first_name text not null,
  last_name text not null,
  email text not null unique,
  password text not null,
  plan text not null default 'free' check (plan in ('free', 'pro', 'enterprise')),
  paypal_subscription_id text,
  paypal_order_id text,
  trial_ends_at timestamp with time zone,
  is_trial_used boolean not null default false,
  video_count integer not null default 0,
  voice_credits integer not null default 0,
  created_at timestamp with time zone not null default now(),
  updated_at timestamp with time zone not null default now()
);

-- Videos table
create table if not exists videos (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references users(id) on delete cascade,
  title text not null,
  prompt text not null,
  style text not null default 'realistic',
  duration integer not null default 15,
  quality text not null default '1080p',
  ratio text not null default '16:9',
  music text default 'none',
  status text not null default 'pending' check (status in ('pending', 'generating', 'completed', 'failed')),
  replicate_prediction_id text,
  video_url text,
  thumbnail_url text,
  error_message text,
  created_at timestamp with time zone not null default now(),
  updated_at timestamp with time zone not null default now()
);

-- Subscriptions table
create table if not exists subscriptions (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null unique references users(id) on delete cascade,
  paypal_subscription_id text not null unique,
  status text not null default 'active' check (status in ('active', 'cancelled', 'suspended')),
  plan text not null check (plan in ('pro', 'enterprise')),
  current_period_start timestamp with time zone,
  current_period_end timestamp with time zone,
  created_at timestamp with time zone not null default now(),
  updated_at timestamp with time zone not null default now()
);

-- Indexes
create index idx_videos_user_id on videos(user_id);
create index idx_videos_created_at on videos(created_at desc);
create index idx_videos_status on videos(status);
3

Configurer PayPal

3.1 — Créer les plans d'abonnement
Dans le Dashboard PayPal Developer, créez 2 plans mensuels.
3.2 — Créer le Webhook PayPal
Le webhook notifie votre serveur quand un abonnement est créé ou annulé.
ℹ️ Pour le développement local, utilisez ngrok pour exposer localhost :
ngrok http 5000 → copiez l'URL https dans le webhook PayPal.

Configurer le Backend

4.1 — Remplir le fichier .env
Ouvrez server/.env et remplacez les valeurs vides par vos vraies clés.
NODE_ENV=development
PORT=5000
CLIENT_URL=http://localhost:3000

# Supabase (copier depuis Project Settings → API)
SUPABASE_URL=https://xxxxxx.supabase.co
SUPABASE_SERVICE_ROLE_KEY=eyJ...

# JWT (générez une chaîne aléatoire longue)
JWT_SECRET=votre_secret_ultra_long_et_aleatoire_123456789
JWT_EXPIRE=7d

# PayPal (copier depuis Developer Dashboard)
PAYPAL_CLIENT_ID=AbCxxxxxxxxxxxx...
PAYPAL_CLIENT_SECRET=EfGxxxxxxxxxxxx...
PAYPAL_PLAN_PRO_ID=P-XXXXXXXXXXXXXXXX...
PAYPAL_PLAN_ENTERPRISE_ID=P-XXXXXXXXXXXXXXXX...
PAYPAL_WEBHOOK_ID=6A6XXXXXXXXXXXX...

# Replicate (copier depuis Account → API Tokens)
REPLICATE_API_TOKEN=r8_xxxxxxxxxxxxxxxx...

# Cloudinary (optionnel — pour stocker les vidéos générées)
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
4.2 — Installer et lancer le backend
cd server
npm install
npm run dev
✅ Si tout est OK, vous verrez :
🚀 Serveur démarré sur le port 5000
🔌 Supabase: Connecté
💳 PayPal: Activé

Dépannage

Erreur "Supabase connecté" n'apparaît pas
Vérifiez que SUPABASE_URL et SUPABASE_SERVICE_ROLE_KEY sont corrects. La service_role_key commence par eyJ.
Erreur PayPal "Unauthorized"
Vérifiez que vous utilisez les clés de l'app dans le bon environnement (Sandbox vs Live). En développement, utilisez les clés Sandbox.
La vidéo reste en "generating" indéfiniment
Vérifiez que REPLICATE_API_TOKEN est valide. Si le token est invalide, la génération échouera silencieusement. Vérifiez aussi les logs du backend.
Le webhook PayPal ne fonctionne pas
En local, utilisez ngrok pour exposer localhost :
ngrok http 5000
Puis mettez à jour l'URL du webhook PayPal avec l'URL https fournie par ngrok.
